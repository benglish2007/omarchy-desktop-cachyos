# Wallpapers

The installer uses the original wallpapers from:

`https://github.com/benglish2007/cyberops-omarchy-theme`

For a completely self-contained repository, copy these three files from that repository into this directory:

- `cyberops-command-deck.png`
- `cyberops-junior-inventor.png`
- `cyberops-girl-inventor.png`

If they are absent, `install.sh` downloads them automatically from the original repository.
